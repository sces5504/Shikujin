## 架構／資產

原生 ES modules + Canvas 2D、固定 60Hz 純模擬、資料／策略 registry、空間索引與上限；UI、存檔、音效均獨立。新增角色可用 standalone portrait asset，不必改既有 atlas。Boss sprite 可選，無資產應使用程序化 fallback。

assets 只含原創生成圖集、OFL 本地字體與授權。字體子集包含程式與 HTML 文字，之後加入新中文字時需更新子集或使用系統 fallback。原生成檔留在 workspace/generated_images，未作公開 runtime 依賴。網站沒有外部字體請求與音樂下載。
