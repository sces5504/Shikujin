# Shikujin 美術基準

2026-10-19：影片 flygame.mp4 已擷取畫面檢視。參考俯視幾何敵人、四面敵潮、發光彈幕；使用者的四張附件僅作色彩與氣質參考。YouTube 連結未直接觀看，不聲稱已還原其特定光影。

- 深海藍黑底、薄荷青主色、粉紅敵彈、琥珀精英敵人、紫色稀有升級。HUD 低干擾，重要互動為高對比青色。
- Canvas 程序化幾何機體、雙層線框、加色發光、粒子與爆炸衝擊環。地圖有不同星雲／軌道遺跡與色調。
- 機庫以大型機體全息預覽、左側作戰資訊、右側整備面板為基準。手機改單欄，HUD 縮排，操作按鈕獨立於拖曳區。
- 原創成年駕駛員赤璃 26、凜 25、雪羽 25、澪 28，四種制服與色調；不沿用附件既有角色姓名與設定。戰敗使用獨立戰損立繪與疲憊通訊；通關使用正常立繪。
- 字體為 Noto Sans TC／Rajdhani（SIL OFL），已隨站點本地託管，缺字使用系統 fallback，不依賴第三方字體請求。
- 光影可關閉震動與降低粒子。DPR 最高 2，避免高密度手機過載。
- 基準畫面放 docs/art/baselines，實際測試畫面先輸出 test-results，驗收後複製必要畫面，勿以未驗證的測試場景作玩法完成證明。

2026-10-19 基準：baselines/hangar-desktop.webp、combat-desktop.webp（1440×960 DPR1）、hangar-mobile.webp（390×844 DPR2、全頁）。建立於本次首個遊戲提交前，對應同次 release checks，畫面含 QA 敵群配置；不作固定時間像素比對。
