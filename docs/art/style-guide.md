# Shikujin 美術基準 1.5

2026-10-19 使用者明確回饋：先前幾何黑底與繪畫式角色不符需求。本版以 Raiden III 實機搜尋圖的軍事機械縱向射擊為戰場方向，人物採使用者附件所示的日系動畫乾淨線稿、清楚色塊與賽璐璐陰影。不要回到柔焦厚塗／泛用手遊寫實畫風。

- 實體機械戰機、六種敵機，地表陰影與火焰爆炸；海岸／峽谷／空港／冰原／熔爐完整場景，少量移動視差，避免方格硬接縫。能量武器有明亮核心、外圈光暈，敵我彈可辨。
- 四位原創成年駕駛員：赤璃26、凜25、雪羽25、澪28；保留既有髮型、瞳色、配色與制服。先有四人主設定，再衍生日常、大絕、回憶、戰損及透明剪影；不要每張CG重新設計人物。
- 戰損為煙灰、疲憊、外套及裝甲損傷，維持衣物遮蔽。回憶為艦內休息室飲品互動。完整CG在休息室／結算；去背CG用在通訊／大絕。
- 左下角色常駐，說話時放大；大絕1.9秒大型去背cut-in，隱藏重複小肖像及波次橫幅。手機等比例縮小，技能鍵獨立於拖曳區。
- 深藍機庫與高對比青色互動保留，戰機預覽使用實體圖像。Noto Sans TC／Rajdhani隨站託管（SIL OFL）；加入新中文字重建子集或系統fallback。
- WebGL批次光暈與預繪火焰效果；自動畫質只降解析度，保留危險碰撞。降低動態效果支援；桌面／手機基準截圖在baselines，實測輸出先至test-results。
