- 5 種 Boss：虛空裁決者、赤燼不死鳥、深淵利維坦、極光神諭、終焉日蝕。五套獨立彈幕策略，半血二階段，預告、攻擊與喘息節奏；專用交戰邊界及畫面外方向提示。

## 呈現與持久化

WebGL 批次精靈／彈幕搭配 Canvas 地表與效果：實體機械戰機、獨立 Boss 圖集、五張完整地表、地面投影、光束、火焰爆炸、連殺 HUD 與放大角色通訊。GPU 不可用時退回 Canvas。角色有正常與戰損立繪；戰損表現凌亂頭髮、煙灰、外套破損與裝甲損傷，保持完整身體遮蔽。通關與失敗使用不同結算文案／角色圖。

原創 WebAudio 合成器配樂隨戰況調整節奏，另有射擊／事件音效；初次操作後才啟用，可分別關閉配樂與音效。減少動態效果設定與系統偏好支援。字體本地化，首載後無第三方 runtime 資源依賴。

localStorage 版本 1：信用點、已購機體、駕駛員、模式難度、研究、成就、紀錄、默契與偏好；向後相容較早 v1。匯出／匯入 JSON，驗證數值與內容 ID。儲存不可用時提示。戰鬥中途不存檔，無跨裝置雲端同步。

狀態：機庫、playing、upgrade、paused、intermission、defeat（含通關）。失焦自動暫停，恢復不追時間；一局獎勵僅結算一次。暫停可主動結算返航。

## 可改造架構

`content` 資料定義、`core` 輸入與儲存、`game` 純模擬／策略 registry、`render` 繪圖與聲音、`ui` DOM 狀態協調。固定 1/60 秒步進。空間索引、連續投射物碰撞、實體與掉落上限。見 architecture.md。

新增 Boss／地圖／角色必須透過資料與策略，不複製主迴圈。資料 ID 是存檔契約。Boss 美術為可選 sprite 欄位，新增策略無貼圖時應保留程序化 fallback。波次頻率集中於 RULES，戰役長度由地圖數與 Boss 頻率決定。

## 1.8 手機與戰鬥回饋（2026-10-19）

來源：使用者本次四項小修／小改。維持既有CG、機械戰場、存檔與穩定ID；針對手機操作、Boss秒殺、flygame華麗度／構築差異改進。

- 移動指標只屬於戰場；大絕／閃避獨立處理任何pointerdown，不依賴多指情境不穩定的合成click。每次按下只觸發一次，保留detail=0的鍵盤／輔助操作click，冷卻及遊戲狀態仍由World決定。放開第二指不重設移動；取消／失焦仍清輸入。
- 戰場與HUD按鈕touch-action:none，頁面其他區manipulation避免雙擊縮放；禁止遊戲字詞選取與iOS長按選單，存檔input／textarea仍可選取複製。不用maximum-scale封鎖全站可及性縮放。
- 五Boss基礎HP為15200／25000／37200／51800／72000，沿用波次與難度倍率（原1900／2500／3100／3700／4500）。不採依玩家傷害自動調血、鎖血、硬性傷害上限或無敵拖時間。既有五機代表性首關／末關構築及Mio大絕、站樁可擊中測試，原約1–4秒→約11–80秒；不是所有真人構築的固定TTK承諾。放大Boss顯示約19.5%、補充動力光，保留二階段、三種攻擊主題與小判定契約。
- 參考flygame放射彈、分岔光線、連鎖命中：新增環星彈幕／折光陣列／衝刺彈倉／臨界反應／冰晶碎裂，加入低溫擊殺、護盾被破、閃避等不同觸發構築。新增流星火網／不屈壁壘進化。一般強化33種、極限3種、進化7種。
- 共用投射物增加star晶彈；普通武器增加短暫砲口光與分層命中火花。火花有0.09秒每敵節流及全局24筆視覺上限，不限制實際傷害；新星彈仍受原我彈500總量契約，敵彈與碰撞完整保留。降低動態效果仍適用。

驗收：原生CDP多指維持移動並按大絕／閃避、放開第二指不中斷、無重複click觸發、雙擊／捏合viewport不變、文字與存檔欄位選取策略；四項純模擬涵蓋五新構築／冷卻／進化及十組Boss時間與二階段；原完整release加新構築全開千彈readback壓測，維持模擬p95<20ms／繪製p95<60ms。
